Built for screenwriters

不是又一个 Markdown 编辑器

从元素类型、封面页到页数估算，编辑器的每个细节都围绕剧本写作，而不是通用文本。

01

专业剧本排版

场景标题、动作、角色、对白、括号提示、转场、分节与备注八类元素；Tab 切换类型，Enter 智能续行，自动保持剧本格式。

02

场景大纲与进度

自动抽取场景列表并可点击跳转，设定目标页数后实时显示完成比例，抬头就知道写到哪里。

03

角色与写作统计

自动提取角色名并支持插入正文；统计字数、场数、预估页数、元素分布，并给出节奏提示。

04

Fountain 互通

导入与导出 .fountain、纯文本及 .screenplay 工程文件，支持粘贴文本解析，可与常见编剧软件交换稿件。

05

导出与打印

封面单独成页的 A4 PDF 导出、系统打印与工程文件导出，写完即可交付阅读。

06

由你定义的工作台

纸张颜色、文字颜色、字体、字号、行距与纸张宽度都可调；左右侧栏拖拽改变宽度，双击恢复默认，设置重启后保留。

Goal-driven agent

写到一半就停？
这次由系统说了算。

普通工具型 Agent 让模型自己宣布「完成」，很容易在整体目标还没达成时收工。剧本工坊把终止权收归系统：模型负责干活，系统负责判断能不能结束。

  1. 1
    先拆目标首轮强制制定任务清单，3–8 个可验收步骤实时显示在 AI 面板。
  2. 2
    持续执行并回灌进度工具调用直接改稿、即时可见；每次结果都附带剩余待办。只输出说明文字会被继续追问，上下文过长自动分段续跑。
  3. 3
    系统验收才允许结束仍有待办、没有计划或编辑次数不足时，finish 会被拒绝并返回剩余项，任务继续推进。

Get started

三步，开始写你的下一场戏

需要 Node.js 20+。不配置 AI 也能完整使用编辑、排版、导入导出与统计功能。

Terminal
# 克隆仓库
git clone https://github.com/456wyc/scriptwriter-studio.git
cd scriptwriter-studio
npm install
npm start
  1. 1
    准备环境安装 Node.js 20 或更高版本，克隆仓库后执行 npm install 安装 Electron 与可选依赖。
  2. 2
    启动编辑器npm start 打开桌面应用；npm run dev 会同时打开 DevTools，方便调试界面。
  3. 3
    按需接入 AI在「AI 助手 → 配置」填写任意 OpenAI 兼容端点的 Base URL、模型与 API Key；密钥经系统加密保存在本机。
